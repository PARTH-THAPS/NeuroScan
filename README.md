# 🧠 NeuroScan – Brain Tumor MRI Classification

NeuroScan is a Machine Learning and Computer Vision project focused on classifying brain MRI images into different categories using image processing and machine learning techniques.

The project aims to explore how computers can analyse medical images, extract meaningful visual features, and identify patterns associated with different brain tumour types.


## 📂 Dataset

This project uses the **Brain Tumor MRI Dataset** created by Masoud Nickparvar.

Dataset source: [Kaggle – Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset)

The training dataset contains four categories:

| Category | Number of Images |
|---|---:|
| Glioma | 1,400 |
| No Tumor | 1,400 |
| Pituitary | 1,400 |
| Meningioma | 1,400 |
| **Total** | **5,600** |


## 🚀 Planned Improvements

- Hyperparameter tuning using GridSearchCV.
- Compare KNN with Random Forest, SVM and Logistic Regression.
- Explore advanced image processing techniques.
- Implement Convolutional Neural Networks (CNNs).
- Explore U-Net for tumour image segmentation using pixel-level annotated masks.
- Develop a visual interface to display classification results and tumour segmentation overlays.

NeuroScan is an educational and experimental Machine Learning project. It is not intended for clinical diagnosis, medical decision-making or replacement of professional medical advice.
